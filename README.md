## Asanali Script (сокращенно aScript)

**Asanali Script** — это легкий, фановый и мощный скриптовый язык программирования, построенный на базе архитектуры (Python и 3.5% C). Он сочетает в себе простоту системных команд батников, гибкость пайтона.

Поддержимаевые функции:<br>
- `echo текст` - выводит текст "текст" на экран<br>
- `let a = 1` - создаёт переменную a со значением 1<br>
- `window(
*css in const style and html in window()*`- создаёт окошко где за интерфейс отвечает монолитный HTML<br>
- `show sys.info` - показывает инфу о системе **ИМЕННО через C файл**<br>
- `class sound {
echo текст
}` - говорит роботизирвоанным голосом слово "текст"<br>
- `$a` - (при a=1) как echo, но уже выносит значение переменной a<br>
