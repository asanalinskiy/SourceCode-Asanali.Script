О языке AsanaliScript

AsanaliScript — это интерпретируемый декларативно-императивный язык программирования со строгой типизацией TypeScript-уровня, лаконичным синтаксисом и встроенными модулями. Язык специально разработан для быстрого построения пользовательских интерфейсов, генерации низкоуровневых звуковых частот, синтеза речи и работы с локальными базами данных.

Архитектура и Синтаксис Языка v2.1.0-TS

Строгая типизация TS

Поддержка интерфейсов и типов данных (string, number, boolean) с валидацией во время выполнения.

Звук и Синтез речи

Встроенный класс class sound для воспроизведения тоновых частот и озвучки текста через робота.

Управление объектами

Поддержка JSON-подобных структур и интерполяции вложенных свойств через синтаксис $massiveVariable.price.

Базы данных и CLI

Встроенное управление локальными JSON-хранилищами и взаимодействие с консолью ОС через модуль cli.*.

Пример кода на AsanaliScript

/* Определение типов и интерфейса */
interface Product {
    id: number
    title: string
}

/* Создание переменной со строгой типизацией */
let version: string = "2.1.0-TS"
let item = { price: 100, name: "Core" }

echo "Запуск AsanaliScript $version..."
echo "Цена компонента: $item.price"

/* Условия и обработка звука */
if $User == "Asanali" {
    class sound {
        echo "Приветствуем разработчика!"
        tone 440
    }
} else {
    echo "Гостевой режим"
}
